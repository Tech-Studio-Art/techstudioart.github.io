Applied Drones

We program existing drones to do real work: firefighting, pollution control, hyperlocal delivery and window washing.

GET IN TOUCH

We don't manufacture drones. We program them.

Good drone hardware already exists. What is missing is software that turns a drone into a dependable tool for one specific job. We write that software for drones that are already on the market, and build each application around a real problem.

Firefighting

Skyscrapers need backup fire suppression. We program drones to reach the places crews cannot get to quickly, such as the upper floors of tall buildings.

Pollution control

Software that sends drones over industrial areas, roads and water to find pollution and help bring it down.

Hyperlocal delivery

Dense urban areas cannot handle more traffic. Drones can carry small parcels over short distances without adding to it.

Window washing

Clean skyscraper windows without scaffolds, ropes or people on the facade.

In progress

All four applications are in development. If you have a drone and a job it should do, we would like to hear about it.
